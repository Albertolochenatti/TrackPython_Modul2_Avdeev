# Abstract Classes Example (Python)

Учебный проект Авдеева АА, демонстрирующий работу с **абстрактными классами** в Python.

## 📌 Описание

В проекте реализованы **3 абстрактных класса**, описывающих различные типы объектов:

1. `PhysicalObject` — физические объекты (материальные сущности)
2. `DigitalService` — цифровые сервисы
3. `Storage` — хранилища данных

Каждый класс содержит:
- 2–3 атрибута с **валидацией**
- 2–3 **абстрактных метода**
- аннотации типов
- документацию (docstring) с примерами использования (**doctest**)

Реализация методов намеренно опущена — используются заглушки (`...`), так как цель проекта — описание интерфейсов и структуры.

---

## 🧱 Структура классов

### `PhysicalObject`
**Атрибуты:**
- `weight: float` — масса объекта
- `material: str` — материал

**Методы:**
- `move(distance: float) -> None`
- `break_object() -> None`

---

### `DigitalService`
**Атрибуты:**
- `name: str` — название сервиса
- `users_count: int` — количество пользователей

**Методы:**
- `register_user(user_id: int) -> bool`
- `delete_user(user_id: int) -> bool`

---

### `Storage`
**Атрибуты:**
- `capacity: int` — ёмкость хранилища
- `used: int` — используемый объём

**Методы:**
- `write(size: int) -> None`
- `clear() -> None`

---
